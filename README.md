\# Hospital Management System



A desktop-based Hospital Management System developed using C#, Windows Forms, and Microsoft SQL Server. The project is designed to support hospital workflows through a graphical desktop application and a relational database.



\# Project Overview



This project demonstrates desktop application development with C#, object-oriented programming concepts, and database integration. It provides an application structure for working with hospital-related information and administrative workflows.



\# Features



The application source code includes modules related to:



\- User Authentication\*\* — Login interface and user access workflow.

\- Patient Management\*\* — Patient-related information and operations.

\- Appointment Management\*\* — Appointment-related workflows.

\- Doctor Management\*\* — Doctor information and administration.

\- Room Management\*\* — Hospital room-related operations.

\- Billing and Payments\*\* — Billing and balance-related modules.

\- Staff Management\*\* — Employee and staff administration.

\- Salary and Absence Management\*\* — Staff salary and absence-related modules.

\- Medical Tests\*\* — Test-related workflows.

\- Reporting and Charts\*\* — Financial or amount-related chart functionality.

\- Chatbot Interface\*\* — A chatbot-related application module.



Feature availability depends on the implemented and configured functionality in the current version. Please verify each feature in the running application before relying on it.

\# Prerequisites



Before running the application, install:



1\. Microsoft Visual Studio with the required .NET desktop development components.

2\. The .NET Framework version targeted by the project.

3\. Microsoft SQL Server.

4\. SQL Server Management Studio (optional, for database administration).



\# Setup and Installation



\## 1. Clone the Repository



git clone https://github.com/MuhaiminIslamUtso/hospital-management-system-csharp.git



\## 2. Open the Solution



Open `Hospital Management System.sln` in Visual Studio from the application project directory.



\## 3. Configure the Database



\- Configure a local SQL Server instance.

\- Verify the database name, schema, tables, and required permissions.

\- Configure the application's connection string for your own SQL Server instance.

\- Use a sanitized database or a verified database initialization script.

\- Do not assume the included SQL script recreates the complete database until all required tables and relationships have been verified.



\## 4. Restore Dependencies



Restore the NuGet packages required by the project through Visual Studio.



\## 5. Build and Run



\- Select the appropriate build configuration.

\- Build the solution.

\- Resolve any missing dependency or database configuration errors.

\- Run the application after successful configuration.



\## Database and Configuration Notes



Database setup may require additional configuration based on the local SQL Server instance.



Do not commit real credentials, private patient records, production database files, or other sensitive information. Use local configuration for machine-specific settings.
